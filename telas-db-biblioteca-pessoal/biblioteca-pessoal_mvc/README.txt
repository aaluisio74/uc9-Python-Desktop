MINHA BIBLIOTECA PESSOAL - MVC

Estrutura:
  main.py                         Inicializa e conecta os componentes
  models/livro_model.py           Model: persistência SQLite
  views/biblioteca_view.py        View: interface Tkinter
  controllers/biblioteca_controller.py Controller: lógica e eventos

Execução:
1. Extraia o ZIP.
2. Abra o terminal na pasta biblioteca_mvc.
3. Execute: python main.py

Requisitos: Python 3 com Tkinter. O sqlite3 já faz parte da biblioteca padrão.
O arquivo biblioteca.db é criado automaticamente na pasta de execução.
